# Phonebook Console Application

Консольное приложение для управления телефонным справочником, написанное на C#. Проект демонстрирует применение принципов чистой архитектуры, SOLID и некоторых паттернов проектирования в реальном приложении. Позволяет добавлять, искать, редактировать, удалять и экспортировать контакты.

## Возможности

- **Управление контактами** – добавление, просмотр, обновление и удаление записей.
- **Поиск** – поиск по имени, телефону или email (без учёта регистра).
- **Группы** – организация контактов по группам и фильтрация по ним.
- **Постоянное хранение** – данные сохраняются в JSON-файл и загружаются при старте.
- **Экспорт в CSV** – выгрузка всех контактов в CSV для использования в табличных редакторах.
- **Удобный консольный интерфейс** – цветовые подсказки, понятные меню.

## Технологии и подходы

- **C# / .NET 6+** – современные возможности языка (LINQ, async/await, nullable-типы).
- **Чистая архитектура** – разделение на слои Domain, Application, Infrastructure, Presentation.
- **SOLID** – единственная ответственность, инверсия зависимостей и др.
- **Паттерны** – Repository (работа с данными), Command (действия меню).
- **Сериализация JSON** – `System.Text.Json` для сохранения контактов.
- **Работа с файлами** – чтение/запись данных и экспорт в CSV.
